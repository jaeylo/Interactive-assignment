# 빛을 찾아, 밖으로 (Light Dungeon)

어두운 던전에서 손전등과 거울을 이용해 빛의 경로를 만들고, 탈출 장치를 작동시키는 2D 퍼즐 게임 프로토타입입니다.

## 게임 소개

플레이어는 손전등으로 주변을 비추며 방을 탐색합니다. 거울의 위치와 각도를 조절해 손전등 빛을 반사시키고, 반사된 빛이 출구 장치에 닿으면 문이 열립니다.

이 프로토타입은 **빛과 거울을 이용한 퍼즐 풀이**를 핵심으로 합니다. 선택적으로 다른 방을 탐색해 자원과 도구를 얻을 수 있지만, 모든 방을 탐험해야만 탈출할 수 있는 구조는 지향하지 않습니다.

## 조작법

- **WASD / 방향키**: 플레이어 이동
- **마우스**: 손전등 방향 조준
- **거울 클릭 후 드래그**: 거울 이동
- **Q / E**: 거울 각도 조절
- **R**: 방 초기화

## 실행 방법

### 로컬에서 실행
`index.html` 파일을 다운로드한 뒤 웹 브라우저에서 열면 됩니다.

### GitHub Pages로 공개하기
1. 저장소에 `index.html`과 `README.md`를 업로드합니다.
2. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서 배포 소스를 `Deploy from a branch`로 설정합니다.
4. 브랜치(보통 `main`)와 폴더(`/root`)를 선택하고 저장합니다.
5. 배포가 완료되면 Pages에 표시되는 주소에서 게임을 실행할 수 있습니다.

## 제작 의도

어두운 공간을 손전등으로 탐색하는 행위와, 거울을 움직여 빛의 경로를 바꾸는 퍼즐을 하나의 플레이 경험으로 연결하는 것이 목표입니다. 플레이어가 직접 위치와 각도를 조절하며 문제를 해결하도록 설계했습니다.

## 현재 상태

- 단일 방 퍼즐 프로토타입
- 손전등 조준 및 어두운 공간 탐색
- 이동·회전 가능한 거울
- 거울 반사와 출구 장치 활성화
- 기본적인 문 열기 및 탈출 목표

이 프로젝트는 개발 중인 프로토타입이며, 향후 플레이 테스트를 바탕으로 퍼즐의 난이도와 피드백을 개선할 예정입니다.
